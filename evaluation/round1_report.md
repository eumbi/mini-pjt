원인별 근거 (trace 의 search_kcd_codes 입력과 결과)
1. 데이터 소견으로는 검색했지만 임상 용어와 KCD-9 공식 명칭이 다르다. "신우신염" → N10 은 '급성 세뇨관-간질신장염', "급성 신손상" → N17.9 는 '상세불명의 급성 신부전', "고중성지방혈증" → E78.1 은 '순수 고글리세라이드혈증', "자발성 세균성 복막염" → K65.0 은 '급성 복막염', "저혈당" → E16.0 은 '혼수를 동반하지 않은 약물유발 저혈당'이다. 15번(J96.01 급성 호흡부전 II형)은 "저산소혈증·고탄산혈증"으로만 검색해 호흡부전 후보가 없었다.
2. 개선 전 시스템 프롬프트의 O 규칙은 "Lab 이상치를 직전 값과 함께, 새 판독을 원문 그대로"뿐이라 투약 변경을 O 에 쓰라는 지시가 없다.
3. 2번 J90 대신 J91(달리 분류된 병태에서의 흉막삼출), 3번 K25.41 대신 K25.01, 5번 D69.6 대신 D69.5(이차성 혈소판감소증)를 골랐다. J91·D69.5 는 임상적으로 근거를 댈 수 있는 선택이라 정답 상병 사람 확인(5건) 때 함께 볼 대상이다. 정답은 바꾸지 않고 리포트에 남긴다.
4. 도구가 '데이터 없음: 등록되지 않은 환자'를 돌려줬는데도 SoapFormatter 가 초안을 만들었다.

모델 비교: 같은 코드의 Haiku 4.5 1차(커밋 f1c5fc0)는 3/20 이었다. Haiku 에서 가장 많던 "메모 증상으로만 검색"과 입력 가드레일의 "(없음)" 메모 거절은 Sonnet 에서는 나오지 않았다.

RAGAS 해석
- context_precision(0.396)이 낮은 것은 KCD 검색 결과가 검색어마다 10건씩 contexts 에 들어가 대부분 정답과 무관하기 때문이다.
- faithfulness(0.475)는 A·P 의 임상 판단 문장(원인 감별, 계획)이 contexts 에 직접 없는 주장으로 잡혀 낮게 나온다.
- answer_relevancy(0.169)는 질문(환자 ID + 짧은 메모)과 답변(SOAP 전체)의 형식 차이가 커서 낮게 나온다.
- context_precision 3건은 RAGAS 평가 호출 시간 초과로 계산되지 않아 평균에서 뺐다.

다음 라운드에서 고칠 것: 원인 2(O 에 투약 변경)와 원인 4(없는 환자)는 T22 커밋에서 이미 고쳤다. 원인 1(KCD 명칭 차이)은 검색 방식이나 정답 상병 확인이 필요해 따로 정한다.
